# Frequently Asked Questions: Flappy Bird Arcade Game

### 1. What is Flappy Bird Arcade Game?
Planned Canvas2D arcade obstacle game featuring physics-based collision detection.

### 2. What technology stack does it use?
Built with HTML5 Canvas, Vanilla JavaScript.

### 3. Where is this project deployed?
Currently running locally in development mode.

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
